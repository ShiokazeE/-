# shiokaze — bio (раскладка как у schuh)

Сетка 2×2 как у schuh.wtf: профиль | «сейчас играет», «обо мне» | история/сообщения.
Плюс два места под персонажей: Люси лежит на верхней кромке правой нижней карточки,
Талия — за текстом в «обо мне».

## Быстрый запуск

```bash
python -m http.server 8000
# http://localhost:8000
```

Или просто открыть `index.html`.

## Источник музыки: ListenBrainz (основной)

Сейчас по умолчанию стоит **ListenBrainz** — открытый проект MetaBrainz.
Ни ключей, ни воркера: API отдаёт `Access-Control-Allow-Origin: *`, браузер ходит напрямую.

### Что нужно сделать (3 шага)

1. Зарегистрироваться: <https://listenbrainz.org/login> (бесплатно, почта).
2. Вписать ник в `js/app.js`:

```js
listenbrainz: { user: 'Sh10kaze' },
```

   или просто открыть `index.html?lb=твой_ник` — тот же результат без правки кода.
3. Скробблить SoundCloud в ListenBrainz:
   - **Web Scrobbler** для Chrome / Firefox / Edge — поддерживает и ListenBrainz, и Last.fm;
   - **Pano Scrobbler** на Android — читает уведомление SoundCloud;
   - в самом SoundCloud интеграции с ListenBrainz нет.

Пока ник не вписан, карточка честно пишет `listenbrainz off` — это не ошибка.

### Что показывает

- последний трек (а если играет прямо сейчас — `playing now` и зелёная точка);
- историю на 6 строк с «N min ago»;
- топ-артистов по последним 20 прослушиваниям;
- ссылку на MusicBrainz у трека;
- обложек ListenBrainz не отдаёт → рисуются монограммы (инициалы + оттенок по хешу).

Проверка живьём: `index.html?lb=rob` (публичный профиль с данными).

## Last.fm (опционально)

Остался как второй источник — твой ник `Japansxow` уже прописан, но для него нужен
Cloudflare-воркер (у last.fm нет CORS, JSONP они больше не отдают).

Переключить источник:

```js
music: 'lastfm',   // вместо 'listenbrainz'
```

или в консоли (`~`): `source lastfm` / `source listenbrainz`.

### Если понадобится Last.fm — деплой воркера (≈2 минуты)

1. Ключ: <https://www.last.fm/api/account/create> → `api_key`.
2. Cloudflare → Workers → `lanyard-proxy` → **Edit code** → Ctrl+A → вставить `worker/worker.js` → **Deploy**.
3. Settings → Variables and Secrets → **Secret**: `LASTFM_API_KEY` = ключ.
4. Проверка: `.../lastfm?method=user.getrecenttracks&user=Japansxow&limit=2`.

Запрос к last.fm делает Cloudflare, поэтому блокировки на стороне пользователя не мешают.

## Визуальный слой (детали и анимации)

Всё построено на CSS-переменных и одном обработчике указателя — без библиотек.

- **Ключевой свет.** Мягкое холодное свечение в `#bg-overlay` ходит за курсором
  (`--gx/--gy`), просвечивает сквозь матовые карточки. Обновление троттлится до ~30 fps,
  чтобы `backdrop-filter` не жёг GPU.
- **Плёночное зерно и диагональный блик** поверх страницы (`#stage::before/::after`) — 4–9 % опасити.
- **Вход.** Карточки поднимаются из блюра каскадом (0.05 → 0.29 с) после входного экрана.
- **Глайдер вкладок.** Пиллю под `history/messages` двигает JS через `transform`, а не фон.
- **История.** Строки появляются со стаггером, на ховере подсвечиваются и сдвигаются на 2 px.
- **Имя.** При наведении на профиль — «дешифровка» как в терминале (`scrambleText`, 520 мс),
  аватар чуть приподнимается и обесцвечивание уходит.
- **Заголовки секций** на ховере карточки растягивают трекинг с .13em до .19em.
- **Звёзды рейтинга** подпрыгивают и «вспыхивают» при клике (`starPop`).
- **Эквалайзер** в плеере и мягкое свечение карточки реагируют на `--audio-mid/--audio-bass`,
  но только когда играет эмбиент (`body.ambience-on`).
- **Баннер профиля** — очень медленный ken burns (28 с).
- **Слоты персонажей** «дышат» голограммой, пока нет PNG.
- **`prefers-reduced-motion`** выключает всё перечисленное.
## Персонажи

Собраны скриптом `tools/make_characters.py` из картинок в `assets/source/`
(в сеть ничего не ходит):

- **Люси** (`assets/lucy.webp`) — PNG, у которого «шахматка» прозрачности была запечена
  в пиксели. Скрипт убирает её: берёт нейтральные серые тона 175–246, оставляет только
  область, связанную с краем (flood fill), иначе выело бы белые волосы; затем эрозия каймы
  и подрезка по содержимому. Фигура лежит на верхней кромке карточки history/messages:
  она вложена внутрь `.feeds`, поэтому рисуется над фоном карточки, но под её шапкой.
- **Талия** (`assets/talia.webp`) — портрет на ровной заливке: фон убран заливкой от краёв,
  сверху и снизу добавлено растворение. Стоит за текстом «обо мне» на 14 %.

Перегенерировать после замены исходников:

```bash
python tools/make_characters.py
```

Скрипт пишет PNG и WebP; страница подключает WebP (36 и 78 КБ).

## Параметры в адресе

| Параметр | Что делает |
|---|---|
| `?enter=1` | пропустить входной экран |
| `?lb=ник` | ListenBrainz без правки кода |
| `?lastfm=ник` | Last.fm без правки кода |
| `?mock=1` | демо-данные |
