## Как обновить сайт через GitHub в браузере

1. Распакуй архив на компьютере.
2. Открой репозиторий сайта на GitHub и выбери **Add file → Upload files**.
3. Перетащи в корень репозитория файлы и папки из распакованной версии: `index.html`, `.nojekyll`, `assets/`, `css/`, `js/`, `worker/`, `tools/` и `README.md`. Не загружай сам ZIP вместо файлов.
4. Подтверди изменения кнопкой **Commit changes**. После сборки GitHub Pages сайт обновится автоматически.

## Важно про Worker

`worker/worker.js` — исходник для Cloudflare Workers, а не файл, который запускает GitHub Pages. Для обновления фронтенда его менять отдельно не нужно. Если будешь обновлять Worker, сохрани в его настройках секрет `LASTFM_API_KEY`; не публикуй сам ключ в репозитории.
